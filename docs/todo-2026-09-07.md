## Implementation notes (2026-09-07)

- Connection recovery preserves login on transient refresh errors, times out stalled connections, and reconnects after a long background suspension.
- Terminal input is encoded as UTF-8 before base64. Regression tests cover straight and smart apostrophes, non-Latin text, and control keys.
- Native iOS paste uses the system paste control and immediately sends the returned text. Physical iOS verification is still needed.
- Native process and running-job menus expose provider-specific plugin actions. The tested `local.session-shortcuts` package is installed and approved locally for plan/normal mode, compact, fork, and Claude model selection. The existing Codex model plugin remains available.
- Model pickers honor explicit checkbox selections, including selecting none; Astra is first. Ordering uses the maintained model catalog because the installed Codex CLI exposes priority, not release dates. Enabled custom models are supported, and mobile refreshes desktop selections while connected.
- Mobile caches 5 recent panes by default, with Off / 5 / 10 in Settings. Contents stay in memory, are bounded, and clear on logout, device changes, and pane exits.
- Desktop pane menus include staged/unstaged Git diffs, status including untracked paths, and worktree browsing with an Open shell action. Creating branches or worktrees is outside this initial view.
- The existing first/latest query rows are combined into one Queries button with a hover popup and a tap/click dialog containing their full text. Complete conversation history is outside this initial view.
- Linux remote-agent installation and attachment remain deferred.

Validation: desktop and mobile TypeScript checks, desktop production build, 10 JavaScript regression tests, 6 plugin tests, 4 Rust Git tests, and isolated browser interaction checks.
